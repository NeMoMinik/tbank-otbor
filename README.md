# T-Библиотека

Консольное приложение для управления личной библиотекой книг.

## Возможности

- Добавление книг с полной информацией
- Просмотр всех книг с сортировкой и фильтрацией
- Избранное для быстрого доступа
- Изменение статуса прочтения
- Поиск по ключевым словам
- Персональные рекомендации
- Сохранение данных в JSON файлы
- Удаление книг

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/NeMoMinik/tbank-otbor.git
cd tbank-otbor
```
2. Установите зависимости:

```bash
pip install -r requirements.txt
```
3. Настройте .env файл (опционально):

```text
BOOKS_DB=books.json
FAVORITES_DB=favorites.json
```
## Использование

Запуск приложения:
```bash
python main.py
```
## Тестирование

Запуск всех тестов:
```bash
pytest tests/ -v
```
Запуск с покрытием кода:
```bash
pytest tests/ --cov=. --cov-report=html
```

Структура проекта

    main.py - точка входа, консольный интерфейс

    library.py - основная логика библиотеки

    models.py - модели данных

    storage.py - работа с файлами

    utils.py - вспомогательные функции

    config.py - конфигурация

    tests/ - юнит-тесты

## Запуск приложения

1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Создайте файл .env с настройками
3. Запустите приложение:
```bash

```
4. Запустите тесты:
